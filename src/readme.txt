Shows information about the current template in the WordPress admin bar, with support for classic, hybrid, and block themes.


== Description ==

Shows the current template name in the WordPress admin bar with helpful details about your theme and template. Works with classic PHP template themes, block themes (Full Site Editing), and hybrid themes.

**Features:**
* Now includes support for block/FSE and hybrid themes
* Shows the template's friendly name and type icon for quick reference
* Admin bar menu dropdown also displays:
  * Template file or slug
  * Theme and parent slugs
  * Template source (e.g. theme or plugin) and if it's been customized
  * Link to edit template in the Site Editor or Theme File Editor


== Installation ==

Use the automatic installer on the 'Plugins' page, or upload the unzipped plugin directory to your `/wp-content/plugins/` directory and activate it.
